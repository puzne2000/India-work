# מכתבי דיקן — משאל חוץ ואישור סוקרים

תיקייה זו מרכזת את החומרים להכנת **מכתבי דיקן ליו"ר ועדת המינויים לאישור סוקרים למשאל חוץ**
(פרוצדורות קידום/קביעות בביה"ס להנדסה ולמדעי המחשב).

## פתוחים / לאימות

- **נמען המכתב** — בטיוטת ברק הונח פרופ' ערן משורר (מהדוגמה). יש לאמת את יו"ר ועדת המינויים
  הנכון לכל מועמד.
- **Shoshana Wodak** (ברשימת ברק) — ציטוטים/h-index משוערים (~23,800 / ~78); אין לה פרופיל
  Google Scholar ציבורי.
- **תאריך המכתב** — יש לעדכן לתאריך השליחה בפועל (עברי + לועזי).
- **שדה "Suggested by"** — נוסף לרשימת הסוקרים בטיוטה (Candidate/Committee) בהתאם לתקנון
  רשימת הסוקרים; אינו מופיע במכתב הדוגמה של סטנובסקי.

## תהליך הכנת מכתב חדש (תקציר)

1. לוקחים את **תבנית ה-Word** (נייר מכתבים + חתימת גיא קינדלר).
2. ממלאים גוף מכתב לפי **ניתוח-מבנה-מכתב-משאל-סוקרים.md** (סעיפים 3–9).
3. פסקאות הרקע/ההישגים נשלפות מ**דו"ח הוועדה** של המועמד.
4. מזריקים את **רשימת הסוקרים** בפורמט האנגלי.
5. מאמתים נמען, תאריך, והתאמת מגדר בפעלים.
