## מטרת המכתב

מכתב רשמי מהדיקן אל **יו"ר ועדת המינויים** (בדרגה הרלוונטית), שבו הדיקן:
1. מבקש **לצאת למשאל חיצוני** (משאל מומחים בחו"ל/בארץ) לצורך קידום ו/או קביעות של חבר סגל.
2. מציג בקצרה את המועמד ואת הישגיו.
3. מדווח על המלצת **הוועדה המקצועית**.
4. מצרף את **רשימת הסוקרים** המוצעת לאישור.

## מבנה המכתב — חלק אחר חלק

### 1. נייר מכתבים (Letterhead) — קבוע
כותרת עליונה ותחתונה בעברית ובאנגלית עם פרטי הדיקן/ית ובית הספר:
- שם ותפקיד הדיקן/ית (למשל "פרופ' שרה כהן, דיקנית")
- "ביה"ס להנדסה ולמדעי המחשב ע"ש רחל וסלים בנין"
- "קמפוס אדמונד י' ספרא, ירושלים 9190401"
- טלפון: 02-5494545
- לוגו האוניברסיטה העברית

> **לשים לב:** בדוגמה הדיקנית היא פרופ' שרה כהן. במכתבים החדשים יש להחליף לשם ולתפקיד של הדיקן הנוכחי (פרופ' גיא קינדלר).

### 2. תאריך — משתנה
מופיע פעמיים: תאריך עברי ותאריך לועזי. לדוגמה:
```
כ"ב אייר תשפ"ה
20 מאי 25
```

### 3. פנייה לנמען — משתנה (לפי דרגת הקידום)
```
פרופ' ערן משורר
ראש הוועדה למינויים לדרגות המעניקות קביעות במדעים הניסויים
האוניברסיטה העברית
```
> יו"ר הוועדה תלוי בדרגה שאליה מקדמים (קביעות / פרופ' חבר / פרופ' מן המניין) ובתחום (מדעים ניסויים וכו').

### 4. שורת "הנדון" — משתנה
```
הנדון: ד"ר גבריאל סטנובסקי
```
שם המועמד/ת, מודגש.

### 5. משפט פתיחה — הבקשה עצמה (תבנית קבועה, פרטים משתנים)
```
הנני מבקש/ת לצאת למשאל חיצוני עבור העלאתו של ד"ר [שם] לדרגת [דרגה] עם קביעות.
```
> יש להתאים: מין הפועל (מבקש/מבקשת), שם המועמד, הדרגה המבוקשת, והאם כולל קביעות.

### 6. פסקת רקע ביוגרפי-אקדמי — משתנה (תוכן), קבוע (מבנה)
פסקה קצרה עם:
- **מסלול השכלה**: תואר ראשון, מוסמך (+מנחה ושנה), דוקטורט (+מנחה ושנה), פוסטדוק (+מוסד ומנחים).
- **מועד וקליטה בביה"ס** ובאיזו דרגה.

### 7. פסקת הישגים מחקריים והוראתיים — משתנה (תוכן), קבוע (מבנה)
מכסה בקצרה:
- **תחום המחקר** ותרומתו.
- **מדדים ביבליומטריים**: מספר פרסומים, h-index, מספר ציטוטים (לפי Google Scholar).
- **אזרחות אקדמית**: תפקידים, ארגון כנסים, ועדות.
- **פרסים ומלגות**.
- **הנחיית סטודנטים** (מספר מוסמך/דוקטורט/פוסטדוק).
- **הוראה**: איכות ההוראה, רשימת מצטיינים, קורסים מרכזיים.
- **מענקי מחקר**.

### 8. פסקת המלצת הוועדה המקצועית — משתנה (פרטים)
```
הוועדה המקצועית בראשותו של פרופ' [שם], דנה בקידומו בתאריך [תאריך] והמליצה
פה אחד להתקדם עם תהליך הקידום והקביעות. אני מצטרפת להמלצה זו ומבקשת אישורך
במשאל למומחים המפורטים להלן:
```
> להתאים: יו"ר הוועדה המקצועית, תאריך הדיון, ונוסח ההמלצה.

### 9. רשימת הסוקרים המוצעים — משתנה
רשימת bullets. לכל סוקר, בפורמט קבוע (באנגלית):
```
• [שם], [מוסד]
  Academic Rank: [Full Professor / Associate Professor / ...]
  Relation: [None / ...]           ← זיקה למועמד (ניגוד עניינים)
  Citations: [מספר]
  h-index: [מספר]
  URL: [דף אישי]
  Email: [אימייל]
```
> בדוגמה יש **13 סוקרים**. מקובל לתת רשימה רחבה (מגוון מוסדות ומדינות, ללא זיקה למועמד).
>
> **הערה על שדה "Suggested by":** במכתב הדוגמה של סטנובסקי אין ציון מי הציע כל סוקר, אך
> תקנון רשימת הסוקרים (כפי שנוסח ע"י איילה) מחייב לציין "הוצע/ה ע"י הוועדה או ע"י המועמד".
> לכן בטיוטות שאנו מכינים נוסף שדה `Suggested by: Candidate/Committee` לכל סוקר.

### 10. חתימה — קבוע/משתנה
```
בברכה,
[חתימה]
פרופ' [שם]
דיקן ביה"ס להנדסה ולמדעי המחשב
```
